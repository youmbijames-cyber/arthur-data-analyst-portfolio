# Data Analyst Portfolio — NADJO YOUMBI Arthur Jeremie

Interactive portfolio with 5 analytics case studies (Excel-style logic + Chart.js dashboards).

## Live site

Enable **GitHub Pages**: Settings → Pages → Source = Deploy from branch → `main` / `/ (root)`.

Then open:

**https://youmbijames-cyber.github.io/arthur-data-analyst-portfolio/**

## Structure

- `index.html` — main portfolio
- `projects/` — interactive dashboards
- `css/` / `js/` — styles and logic

## Customize

Edit email / LinkedIn in `js/main.js` (`CONFIG` object).
